# 🐍 Snake Game (Python OOP + Turtle)

A classic Snake Game built using Python, following Object-Oriented Programming (OOP) principles and the built-in turtle graphics library.<br>
This project demonstrates modular design, class-based architecture, and real-time game mechanics using Screen and Turtle.<br>

## 🎮 Features<br>

🐍 Snake movement using arrow keys<br>
🍎 Random food generation<br>
📈 Score tracking system<br>
💥 Collision detection:<br>
Wall collisio<br>
Self collision<br>
🔁 Game restart logic (if implemented)<br>
🧱 Clean OOP structure with separate modules<br>

## 🧠 OOP Concepts Used<br>
Classes and Objects<br>
Constructor (__init__)<br>
Instance Methods<br>
Encapsulation<br>
Modular Programming<br>
Separation of Concerns<br>
### Each component of the game is handled by its own class:<br>
Snake → Controls movement and growth<br>
Food → Generates random food positions<br>
Score → Displays and updates score<br>
main.py → Controls the game loop and event listeners<br>


## 🚀 How to Run<br>
1️⃣ Clone the Repository<br>
git clone https://github.com/your-username/snake-game.git<br>
cd snake-game
2️⃣ (Optional) Create Virtual Environment<br>
python -m venv venv

Activate it:<br>
Windows:<br>
venv\Scripts\activate<br>

Mac/Linux<br>:
source venv/bin/activate<br>

3️⃣ Run the Game<br>
python main.py<br>
🎮 Controls<br>
Key	Action<br>
⬆ Arrow	Move Up<br>
⬇ Arrow	Move Down<br>
⬅ Arrow	Move Left<br>
➡ Arrow	Move Right<br>
